# 🛒 Blinkit Clone (Frontend)

A responsive frontend clone of the popular instant-delivery platform **Blinkit**, built using semantic **HTML5** and modern **CSS3** (Flexbox & Media Queries).

---

## 📸 Preview

| Desktop View | Mobile View |
| :---: | :---: |
| Full navigation bar, logo, search input & cart button | Adaptive mobile header with auto-collapsed logo & user profile icon |

---

## ✨ Features

- **Responsive Header**: Dynamically switches layouts between desktop and mobile devices.
- **Adaptive Logo/Profile**: Automatically hides the desktop logo and displays a mobile user profile icon on smaller viewports.
- **Search Bar & Action Triggers**: Clean layout mimicking Blinkit's quick-commerce search bar and cart buttons.
- **Pure CSS Layout**: Crafted using Flexbox, CSS box-sizing models, and fluid sizing without external heavy frameworks.
- **Font Awesome Icons**: Crisp vector icons for UI actions.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic page structure
- **CSS3** — Custom styling, Flexbox layout, and CSS media queries
- **Font Awesome 6** — UI icons (`fa-circle-user`, search, etc.)
